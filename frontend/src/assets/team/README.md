# Team photos

Add the four final team photographs to this folder using these exact filenames:

```text
jagdish-butte.webp
mahim-jain.webp
shaurya-pandey.webp
aditya-sabale.webp
```

No source-code change is required after adding them. The About page detects
these WebP files during the frontend build and places each photo in the matching
team card.

Until a photo exists—or if a photo cannot be loaded—the existing botanical
background and initials remain visible automatically.

For consistent cropping, use photographs with the same dimensions and keep each
person's face near the horizontal centre and upper half of the image.
